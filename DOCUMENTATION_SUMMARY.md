## 💻 Quick Start (30 Detik)

```powershell
# 1. Setup (sekali saja)
$git = "C:\git-portable\cmd\git.exe"
& $git config --global user.name "Your Name"
& $git config --global user.email "your@email.com"

# 2. Push
cd 'C:\Users\Interbat\Work-Order-Eng'
& $git add .
& $git commit -m "feat: Add login and admin settings"
& $git push origin main

# 3. Done! 🎉
```

## 💡 Pro Tips

1. **Simpan token di tempat aman** - Jangan share dengan orang lain
2. **Commit message yang clear** - Agar mudah dipahami
3. **Pull sebelum push** - Untuk avoid conflicts
4. **Practice regularly** - Lakukan push/pull beberapa kali sampai terbiasa
5. **Baca error message** - Error message adalah teman terbaik Anda
